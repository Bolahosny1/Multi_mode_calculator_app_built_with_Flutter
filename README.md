📱 Calculator With All Modes – Flutter

A fully functional multi-mode calculator app built with Flutter, designed to provide a smooth, modern, and responsive user experience.
This project demonstrates clean UI design, efficient state management, and modular Flutter architecture.

The app supports multiple calculation modes in one place, making it suitable for everyday use as well as learning Flutter fundamentals.

✨ Features

🧮 Standard Calculator

Basic arithmetic operations (Addition, Subtraction, Multiplication, Division)

🔢 Scientific Mode

Trigonometric functions

Powers, roots, and logarithmic operations

📐 Advanced Calculations

Percentage

Brackets handling

🎨 Modern UI

Clean and intuitive layout

Responsive design for different screen sizes

⚡ Fast & Lightweight

Optimized Flutter performance

🧩 Well-Structured Code

Easy to understand and extend

🛠️ Built With

Flutter

Dart

Material Design

🚀 Purpose

This project is created to:

Practice Flutter UI and logic

Demonstrate handling multiple calculator modes

Serve as a base for future enhancements (themes, history, unit converter, etc.)
